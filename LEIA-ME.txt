    public/css/style.css        public/index.html
    public/js/api.js            public/js/app.js
    server/config.js            server/db.js            server/index.js
    server/util.js              server/routes/api.js    server/routes/admin.js
    server/services/songs.js    server/services/cupons.js (novo)
    server/services/instagram.js (novo)
    README.md

  Arquivos com ponto (o arrastar-e-soltar do GitHub ignora): crie pelo
  "Add file → Create new file", colando o conteúdo:
    .env.example   (atualizado: novas variáveis PRICE_*_DE, CUPOM_*, IG_*, WHATSAPP_DELIVERY, EVOLUTION_WEBHOOK_SECRET)
    .gitignore     (ainda não está no repositório — importante: evita subir data/ e .env)
